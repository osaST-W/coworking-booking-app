## 📱 О проекте

Мобильное Android-приложение, позволяющее пользователям просматривать доступные рабочие места в коворкинге и оформлять бронирование через удобный интерфейс.

## ⚙️ Технологический стек

| Компонент | Технология |
|-----------|------------|
| Платформа | Android (minSdk 24, targetSdk 34) |
| Язык | Java |
| Разметка UI | XML |
| База данных | SQLite (SQLiteOpenHelper) |
| IDE | Android Studio |

## 📋 Функциональность

- Просмотр каталога рабочих мест с фильтрацией по категориям
- Оформление бронирования с выбором даты и временного слота
- Алгоритм проверки конфликтов (предотвращение двойного бронирования)
- Автоматический расчёт стоимости аренды
- История бронирований пользователя
- Генерация QR-пропуска для доступа к рабочему месту
